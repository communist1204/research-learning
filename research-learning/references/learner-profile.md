# 学习者画像

新会话仅使用学习者明确提供的背景、已配置资料库中的有效记录及本轮反馈。未提供的条目保持待确认，按当前材料继续。只记录会影响教学的背景。

## 私有画像可记录的条目

- 当前研究方向、目标、所需学习深度，以及暂时不优先的主题。
- 本人已深入掌握的科研内容，实际系统学习过的书籍版本和章节，或已掌握的实现及复现经验。
- 对方法、公式作用、推导和实现分别说明已有基础、证据和已知缺口。作者身份、发表状态和知识掌握分开；保留用户明确指出的具体例外。
- 当前有效的表达、互动和归档偏好。用户最新反馈与具体掌握记录优先于概括画像。

## 默认教学偏好

- 先由 agent 深入理解，再用最简单的大白话讲主线。进入细讲时继续用同样的大白话。两轮讲解、重讲和答疑中的每一句都要短，一个句子尽量只说明一件事。不能把细节版写成长难句或大段术语。完整性与易读性并重，细节暂缓到第二轮不等于省略；原文每项实质内容都应有易懂解释。论文详细交互以 [paper-reading.md](paper-reading.md) 为准；主文件“首要教学原则”及书籍专属流程继续适用。
- 真实图片、视频、数据与代码仅在比纯文字更有助理解时按需使用，用于避免空泛和抽象；不强制每次检索，不为引入真实材料把内容讲复杂，不偏离当前论文主线。

- 论文、书籍和明确配套笔记放用户指定的专属资料库，与其他个人文档、聊天和零散图片分开；检索与积累判断限定本库及当前明确指定材料，不自动扩展到个人总库。
- Codex 以实际 agent 主动备课、安排、调用工具和归档，后台可复杂、入口要简单。
- 用户主要看、听、追问，不希望自己逐处截图或设计提示词；不把交互变成频繁考试。
- 论文阅读流程依 [paper-reading.md](paper-reading.md) 执行。保留先查官方代码、工程化讲清整篇方法并等待开始的导读。正式精读每小节强制分成两个独立对话回合。第一回合只给忠实翻译与返璞归真解释，随后停下。没懂就换讲法。用户之后明确要求细讲时，才在第二回合沿原文补齐概念、步骤、图表、公式、推导、代码、例子、条件及限制，随后再次停下。按主文件约定可概要的部分仍标明范围；不把自然一节自动缩成一句。书籍保留译后等待，进入讲解后也按入门、停顿、细讲、停顿执行。
- 论文当前阶段与“继续”依 [paper-reading.md](paper-reading.md) 处理。第一回合之后明确要求细讲才进入本节第二回合。只说“懂了”继续等待。单说“继续”且意图不清时只简短问清，已有明确约定不重复问。细讲未完则按用户意图续讲本节。书籍仍按主文件译后等待及两轮流程。用户可随时明确要求只翻译、跳过细讲、跳节或暂停。跳到下一小节必须重新从忠实翻译与返璞归真开始，随后停下。翻页、继续、读过或无提问都不能等同掌握；第一轮后的“懂了”也只支持自评理解主线，不扩大为整节细节已掌握。
- 赞成查相关原论文、顶会/顶刊成果或理论资料补充关键缺失解释；补充以读懂当前原文为目的，顺带提及而不影响理解的内容不必展开。补基础依领域与实际疑点灵活决定，不设统一基础课。
- 重视原图、公式数值例子、样本、信息流和论文—代码对应；没懂就换讲法。
- 关注机制和真正贡献。
- 阅读历史采用简短标注：读完、切换到另一篇、明确结束/暂停或要求保存时汇总读到哪里、理解了什么及未解决问题；不要每读一点就持久记一点。需要详细精读笔记时再单独整理。
- 阅读记录与知识积累相联：在上述节点顺带更新有依据的主题积累层次，用于后续论文解释和科研学习；不只统计读过多少篇，不机械用阅读次数给能力打分。
- 每份论文/书籍都要独立的简短掌握记录，逐项区分理解范围和缺口，并可关联零到多份用户自我笔记。原笔记保留，个人理解与摘抄/AI 内容分清；无需上传笔记才承认明确自述。
- 资料库可只保留对当前研究有用的材料。允许仅有自述的有效背景，不要求补全旧文件或逐篇接受测验。

## 教学范围与深度

- 用户指定的原文范围及逐小节推进方式依 [paper-reading.md](paper-reading.md) 执行。保持原有完整性、衔接、维度说明及短句连贯要求。
- 学习深度按当前研究关系选择了解原理、掌握计算实现或针对性深入推导；先建最小必要基础，大部分时间用于相关论文和真实项目。此目标不自动改变已有强中弱掌握证据。书籍保留译后等待再分入门、停顿、细讲、停顿。

## 更新

在用户的私有资料库中维护个人画像。用户明确变更或实际解释/应用提供证据后增量更新。不要由“继续”推断掌握，不由一次疑问评价整体数学/英语水平。单篇进度放文库状态，不放本画像。
