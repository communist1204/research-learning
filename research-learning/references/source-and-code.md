# 原文、LaTeX、图表与代码核验

论文整篇方法导读先按主文件阶段一查找官方代码与主要方法，阅读足以还原真实操作、训练和推理的实现；无官方代码时按原文说明可核验范围。其余源码、图表与实现核验按当前理解问题选用，不要求每篇、每节全部执行。已有材料复用；材料缺失时说明具体缺口并继续可做的部分。不声称拥有上游未安装的脚本，也不把“具备流程”说成“已经下载/运行”。

遇到用户纠错、投影/坐标方向、符号/维度/时间步、图文与代码冲突或实验数值疑点时，执行 [VISTA 主动证据检查闭环](vista-evidence-revisit.md)：定位确切版本与位置 → 打开相应原文/原始页图 → 对比相关实现 → 用短句给出证据支持的结论 → 按原有写入节点更正档案。图像或排版相关疑点必须实际查看页图，不能以摘要、OCR 或模型记忆代替；材料不可用时明确缺口，不伪称已核验。

## PDF 与 LaTeX 源码

- 从用户材料、论文官方页面或 arXiv 获取匹配版本的 PDF；有公开 LaTeX source 时按需获取。保留论文版本与来源，避免把最新源码套到旧版 PDF。
- 解析主 tex、相关的 `input/include` 文件、自定义宏和参考文献，建立需要的章节、公式、图表与引用位置。必要时拍平为工作副本，但保留到原始文件的定位；不必为了读一小节重建整个出版工程。
- 优先利用源码检查复杂公式、上下标、求和范围、表格列对齐及图注/标签；将公式编号和内容对回实际 PDF。区分定义、推导、假设与作者省略的步骤，讲解时只展开当前需要的数学。
- 源码中的注释、被注释掉的段落与草稿不算已发表结论；源码和 PDF 不一致时按用户选定版本定位差异，不默默拼接。未经必要性判断不执行编译脚本或启用 shell escape。
- 无源码时用 PDF 提取文本加页面渲染核对；复杂公式或错位表格以实际页面为准，不能以错误提取结果硬讲。源码帮助读懂内容，不要求用户学习 LaTeX 排版。

## 原图与表格

- 实际查看准备讲解的原图，先解释图的组织与读法，再解释模块/箭头；图注不能替代看图。
- 按需从 PDF 裁图、放大局部或单独显示公式/表格，检查完整性与清晰度；保留图号、页码、版本。不要自动重画成貌似原图的图片。
- 表格数字、单位、脚注、最优标记须对齐核验；源码和页面互证，教学示意与作者结果分开。

## 按需用真实材料解释抽象概念

- 先明确当前原文中哪个点仅靠文字不易理解，再选择最小的一张图、一段视频、一条样本或代码片段。能用短句讲清时，不额外搜索；现有材料足够时直接复用。
- 优先当前论文及其官方项目；必要时补充相关原论文与官方数据/代码。不以顶会顶刊名号代替相关性和核验，不把补充项目变成新的讲解主线。
- 展示前实际查看；展示后用短句指出哪里是对象、输入、输出及其对应关系，只解释当前原文需要的部分。不能只贴链接，也不能为了“真实”列出所有字段、接口和实现细节。材料应减少理解负担，不能增加负担。
- 区分数据集样本、项目演示、模型测试视频和教学示例；未核实同一条记录时，不把图片、语言和动作数值拼成一个真实配对样本。没有读出的数值不编造；无法获取时简短说明，改用明确标注的简单教学例子。
- 补充完成后回到原文对应论点，检查是否仍完整解释了原文条件和细节；外部材料不能挤掉原文内容。

## 找代码并沿论文讲解

- 先查原文、作者官方项目页与已确认的作者仓库；论文未附链接时检索方法名加 official code/GitHub。核对作者/机构、方法和版本；第三方复现明确标注，不冒充官方实现。
- 记录实际读取的分支/提交。先定位 README/config、模型 forward、loss、dataset/transform、推理和评测入口，再按当前疑点读相关函数；不默认全仓库逐行读。
- 将论文公式或模块对应到必要代码行，解释输入输出、张量形状、预处理、冻结/更新、训练/推理差异。讲解用户感兴趣的实现，而不是仅丢一个仓库链接。
- 发现时间方向、参数化、额外损失、默认配置或数据处理与论文不同，分别说明两者及所用版本；代码不是自动正确，未经运行不能称已验证行为或复现实验。
- 用户要“走一个例子”时优先使用公开样本/官方 demo，沿当前机制串起数据与代码；可独立小数值演算。缺数据用标注的教学例子，不编造真实测量值、实际模型尺寸或成绩。
- 无官方代码时仍可按原文讲解，并明确不能核实的实现细节；伪代码标明为教学重述。除非用户要求，不安装仓库依赖、不跑训练，不替用户项目做改动。
