# 科研资料范围与检索边界

## 指定资料库

用户可指定一个专属持久资料库，例如 ChatGPT Library 内的个人目录，或可读写的本地私有目录。先确认根目录、档案子目录与索引的路径或稳定标识。若工具可用，可在指定根目录内定位已存在的索引。未配置时使用用户本轮明确指定的材料继续，不扫描总库或自动建立替代库。没有持久存储能力时保留当前会话进度，明确归档状态。

下面是可选的目录组织方式，使用已有结构时沿用对应位置。

| 示例位置 | 用途 |
| --- | --- |
| `01_本人研究论文` | 用户明确纳入的本人研究论文 |
| `02_阅读论文` | 待读、在读和已读论文，状态由档案区分 |
| `03_书籍` | 用户明确纳入的学习书籍及版本 |
| `04_配套笔记` | 与库内论文或书籍明确关联的笔记与总结 |
| `05_阅读与知识档案` | 阅读位置、知识积累及来源索引，如 `阅读档案索引.md` |

## 允许与排除

- 默认只用上述目录内的相关论文、书籍、已关联配套笔记和本系统档案；加上用户本次明确指定用于阅读/入库的材料，以及当前阅读中的直接反馈和教学偏好。
- 不扫描整个个人文件库来补齐背景，不读库外无关文档、图片或其他聊天，不调用跨聊天个人历史检索来判断知识积累。即使平台上下文提供了其他聊天的记忆摘要，也不把其中未经本系统确认的信息作为材料或知识程度依据。
- 资料缺失时不自动扩大范围到总库或旧聊天；说明本库尚无该材料，使用当前明确给出的内容，必要时请用户指定目标。旧画像中来源含糊的历史推断不作为积累依据；保留本系统已经由用户明确确认的知识与偏好。
- 配套笔记需有对应论文/书籍与适用章节；保留原始笔记，区分本人理解、摘抄、AI补充与未解决疑问。未声明用途的截图或其他随手上传文件不自动入库。
- 论文/书籍内的原图、公式截图和可追溯的裁图可用于当前教学；不能因此把个人图片库当资料源。只有用户明确指定的配套手写笔记图片才按笔记处理。
- 学术补充：可为理解当前原文查询公开原论文、权威理论资料和官方代码，并标明外部来源；它们不是个人已读经历，不自动升级知识积累或混入资料库。用户明确纳入后才建相应记录。

## 具体检索与保存

1. 先按已知稳定标识或路径读取索引，定位当前材料；新任务若需核对文件是否仍在库内，用根目录下的列表或带范围的搜索确认，不读取库外内容来验证。
2. 列表限定在指定根目录或已知子目录。搜索限定到这些目录，或使用已验证属于本库的文件引用。若 ChatGPT Library 工具支持 `scope.library_folders` 或 `scope.file_refs`，相应使用这些参数。无法确定参数时先限定目录列表再按文件读取，禁止退回无范围搜索。
3. 索引失效时只在本库“阅读与知识档案”目录定位；根目录缺失/权限不足则说明，不通过全库扫描或旧聊天自动重建。
4. 新增论文/书籍/明确配套笔记放对应子目录；上传到当前聊天不等于已经归入本库。完成保存或移动后核对结果，保留稳定文件身份；不把未归档材料说成已持久保存。
5. 阅读和知识档案写入已配置的档案目录；每项正式登记材料的独立掌握记录、可选个人笔记关联按 material-records.md。替换时保留原文件身份与目录，不能意外写回总库根目录。保存频率仍按 session-records.md，目录隔离不触发逐轮记录。
6. 用户移出本库的材料不再自动检索；撤回、删除与派生积累按档案规则处理。未明确要求时不删除库外文件，不批量搬入总库里看似相关的旧材料。
